# Оптический CANopen-сканер DataMatrix (RPi CM4 + OV9281)

## 1. Параметры CAN
* **Скорость:** 1 Мбит/с (`1000000`)
* **Node ID:** `0x01`
* **Boot-up:** `can0 701 [1] 00`
* **SDO проверка связи (DeviceType 0x1000 sub 0):** поддерживается, сканер отвечает на `0x601` стандартным кадром `0x581 [8] 43 00 10 00 00 00 00 00`.

---

## 2. Команды управления

### CANopen NMT Master (COB-ID: `0x000`)
| Команда | Hex | Описание |
| :--- | :--- | :--- |
| `cansend can0 000#0101` | `01 01` | **OPERATIONAL:** сканирование ВКЛ, передача TPDO ВКЛ, подсветка ВКЛ |
| `cansend can0 000#8001` | `80 01` | **PRE-OPERATIONAL:** пауза передачи, подсветка ВЫКЛ |
| `cansend can0 000#0201` | `02 01` | **STOPPED:** остановка |
| `cansend can0 000#8101` | `81 01` | **RESET NODE:** программный сброс, отправка Boot-up `701#00` |

### Прямые команды iRAYPLE и управление светом (COB-ID: `0x201`)
| Команда | Hex | Описание |
| :--- | :--- | :--- |
| `cansend can0 201#FC03` | `FC 03` | **Старт:** сканирование + передача TPDO + подсветка ВКЛ |
| `cansend can0 201#F807` | `F8 07` | **Пауза:** остановка TPDO + подсветка ВЫКЛ |
| `cansend can0 201#C837` | `C8 37` | **Single Shot:** принудительная отправка одного кадра TPDO |
| `cansend can0 201#0000` | `00 00` | **Только подсветка ВЫКЛ** *(сканер продолжает работу и передачу TPDO)* |
| `cansend can0 201#0001` | `00 01` | **Только подсветка ВКЛ** |

## 3. Исходящие телеграммы TPDO

Все числовые поля упакованы в **Big-Endian** (старший байт вперёд). Передача идёт по событию (смена ID или $\Delta \text{Angle} \ge 0.2^\circ$), период не чаще 10 мс (100 Гц).

### TPDO2: Угол поворота (COB-ID: `0x281`)
* Длина: 8 байт
* **Байты 4..5 (`int16`, Big-Endian):** $\text{Angle} \times 10$ (диапазон `-1800` .. `+1800` = $-180.0^\circ$ .. $+180.0^\circ$).  
  *Пример парсинга на C:* `(float)((int16_t)(data[4] << 8 | data[5])) / 10.0f`
* Остальные байты зарезервированы (`0x00`).

### TPDO3: Видимость и ID метки (COB-ID: `0x381`)
* Длина: 8 байт
* **Байт 0 (Флаги):**
  * `0x08` (Бит 3) — `visibility` (`1` — метка найдена в кадре, `0` — метки нет).  
  *Пример парсинга на C:* `visibility = data[0] & 0x08;`
* **Байты 4..7 (`uint32`, Big-Endian):** числовой номер распознанной метки DataMatrix.  
  *Пример парсинга на C:* `(uint32_t)(data[4] << 24 | data[5] << 16 | data[6] << 8 | data[7])`
